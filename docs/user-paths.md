## How the two paths differ

`src/api/bridge.ts:639` — `createBridge()` returns `TauriBridge` when `__TAURI_INTERNALS__` is on
`window`, else `DemoBridge`. The two classes implement the same `DataBridge` interface
(`src/api/bridge.ts:20`), so **every row below has a desktop path and a browser-demo path**, and the
demo one is a complete in-memory fake (seeded profiles, fixed fixtures, `wait()` delays). The
browser demo is labelled in the UI (`App.tsx:63` `DEMO` banner), so it is not disguised as the
desktop product.

Registered Tauri commands — the full backend surface — `src-tauri/src/lib.rs:21-33`:
`list_connections`, `profile_load_warnings`, `save_connection_with_secret`, `remove_connection`,
`test_connection`, `connect`, `disconnect`, `load_metadata`, `execute_query`, `save_ai_secret`,
`ai_chat`. **No mutation command is registered**, which matches the documented read-only posture.
